Endgame logger for HSR Endgame Clears. You will need your own Filess MYSQL account. The methods for retrieving a character's splash art (both big and small) don't always work for characters with atypical names
(Think: Remembrance Trailblazer, Hunt March, Dan Heng Imbibitor Lunae). However, as there is currently no frontend application using those images, this is not a pressing issue.

Previous ideas were to use Hoyolab to get data. I just recalled Prydwen's own project (https://github.com/LvlUrArti/MocStats) as I was writing this. A future variant of this project may take inpsiration from Prydwen's 
project while also collating the information about each character instead of web scraping it each time. I wanted to attempt web scraping in this project and I wasn't really developing this project as a tool for 
universal usage, which is why I didn't make it as such. 

Please do not use my Filess database even though I know you can. It is a free account, so I am fairly certain that I will not incur any costs through internet strangers. However, I would still prefer it if my filess
account was left alone. Thank you.
